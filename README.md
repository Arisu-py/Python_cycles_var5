# Теоретическая справка

## Оператор цикла while
Оператор цикла while используется в случае, когда мы выполняем какие-либо действия, пока условие истинно.

### Пример использования:
```
while *<условие>*:
  *<Исполняемый код>*
```

## Оператор цикла for
Оператор цикла for используется в случае, когда нам необходимо пройти какую-либо коллекцию или диапазон, с которым мы выполняем какие-либо действия, или выполнить определённое количество раз определённый код.

В качестве диапазона мы можем использовать функцию *range(N)*

### Пример использования:
```
for element in elements:
  *<Исполняемый код>*
```

## Оператор цикла else
Оператор else в контексте циклов используется в случаях, когда нам необходимо выполнить определённый код, в случае естественного завершения цикла. (Т.е. не использовался break и другие методы)

### Пример использования:
```
for i in range(5):
  if i==3:
    break
else:
  print('Цикл успешно завершился')
```
В данном примере блок else не будет отработан, так как цикл прервёт break.
